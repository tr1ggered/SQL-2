# SQL Bootcamp — множества и JOIN

Практика операций над множествами и объединения таблиц в PostgreSQL.

## Что я сделал

- применил `UNION`, `INTERSECT` и `EXCEPT`, включая работу с дубликатами;
- использовал декартово произведение и разные варианты `JOIN`;
- сравнил подзапросы на `IN` и `EXISTS`;
- решил задачи анализа связанных данных о людях, заказах и пиццериях.
